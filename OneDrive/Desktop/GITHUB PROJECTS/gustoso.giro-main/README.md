## About GustosoGiro

GustosoGiro is a vibrant food blog that celebrates culinary adventures from around the world. From traditional Filipino dishes like halo-halo to classic Italian recipes like Margherita pizza, we explore the rich tapestry of global cuisine through engaging content, detailed recipes, and honest restaurant reviews.

## Features

- **Featured Recipes** - Step-by-step cooking guides with detailed instructions
- **Food Blogs** - Engaging articles about culinary experiences and food culture
- **Restaurant Reviews** - Honest reviews of local cafes and restaurants
- **About Us** - Meet the passionate food bloggers behind GustosoGiro
- **Responsive Design** - Optimized for all devices and screen sizes

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/blueztian/gustoso.giro.git
   cd gustoso.giro
   ```

2. Open in your browser
   - Simply open `index.html` in your preferred web browser
   - No additional setup required!
